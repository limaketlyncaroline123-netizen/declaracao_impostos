# 🦉 Owltax

**Owltax** é uma planilha desenvolvida no Microsoft Excel para organizar informações cadastrais e financeiras, incluindo rendimentos bancários e entradas de valores.

---

## 📌 Sobre o projeto

O projeto reúne informações importantes em um único arquivo, facilitando o preenchimento, a organização e a consulta dos dados.

## ✨ Funcionalidades

- **Dados do titular:** organização de informações cadastrais.
- **Rendimentos bancários:** registro de instituições financeiras, valores e identificação de anexos.
- **Notas e entradas financeiras:** organização de entradas por data, categoria e valor.
- **Tabela de bancos:** lista de instituições para auxiliar no preenchimento.
- **Cálculo automático:** soma dos valores informados na seção de rendimentos bancários.

## 🛠️ Ferramentas utilizadas

- Microsoft Excel
- Fórmulas e recursos de organização de dados em planilhas

## 🚀 Como utilizar

1. Baixe o arquivo Excel disponível neste repositório.
2. Abra-o no Microsoft Excel ou em um programa compatível.
3. Preencha os campos com os dados desejados.
4. Confira as informações e os valores registrados.

## ⚠️ Aviso

Este projeto tem finalidade organizacional e educacional. Ele não substitui orientação contábil ou tributária profissional.
